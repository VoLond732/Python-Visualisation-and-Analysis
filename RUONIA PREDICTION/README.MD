Цель данной работы — моделирование поведения ставки RUONIA и ее прогнозирование с помощью эконометрического анализа.

Источники данных: Центральный Банк Российской Федерации (https://www.cbr.ru/), Федеральная служба государственной статистики Российской Федерации (данные о ценах и инфляции: https://rosstat.gov.ru/statistics/price).
